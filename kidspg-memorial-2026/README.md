### プロンプトを追加・差し替えるには

グループ見出しは `<h3 class="group-title">`、その説明は `<p class="group-note">` です。
カードを足すときは、入れたいグループの中に `<article class="prompt">` を置いてください。

`2026-gummy-memorial.html` の `<article class="prompt">` を丸ごとコピーして、
次の4か所を書き換えるだけです。**JavaScript は触らなくてよい**設計にしています。

- `<h3 class="prompt-title">` … ゲームの名前
- `<span class="prompt-level">` … むずかしさ
- `<p class="prompt-desc">` … どんなゲームができるか
- `<pre>` の中身 … プロンプト本文

`<pre>` の中に `<` `>` `&` を書くときは `&lt;` `&gt;` `&amp;` に置き換えてください。
